## Overview

Hubble is an algorithmic monetary protocol on Sonic featuring an epoch-based peg system, liquid redemption reserves, protocol-token staking, and incentivized liquidity pools.

The protocol includes:

- HUBBLE and its escrowed staking representation, xHUBBLE
- EX and its escrowed staking representation, xEX
- Mission Control staking and liquidity incentives
- An on-chain stS redemption reserve
- HUBBLE/USDC and EX/stS liquidity markets
- On-chain TWAP-based price and epoch calculations

This repository is being assembled incrementally. Contracts, interfaces, documentation, deployment records, and supporting applications will be published here as they are reviewed and prepared for public release.
